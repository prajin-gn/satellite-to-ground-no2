# Data

## Description
The directory contains all the data needed to train the model.

## Content 
``` bash
data
├── processed
│   └── .gitkeep
├── raw
│   └── .gitkeep
└── README.md
```

## Usage
1. The ground station data containing NO2 values is downloaded from [CPCB continuous monitoring air quality data for India, from 2015-2019](http://arks.princeton.edu/ark:/88435/dsp01zw12z843p)

2. From the downloaded folder copy the **no2_ccr_copy** folder into /raw directory.
